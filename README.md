# LogSID Project Page

Anonymous project website for **LogSID: Detecting Sensitive Information in Large-Scale Logs**.

- [Project website](https://logsid.github.io/)
- [Source code and run commands](https://github.com/logsid/logsid)
- [Code release](https://github.com/logsid/logsid/releases/latest)

The benchmark is hosted on Zenodo. The website's Dataset link provides anonymous, read-only access to all eight sources.

This repository contains the static website, four figures, and two accessible HTML tables aligned with the submitted paper. The page selects paper Figures 1, 2, 5, and 6 and Tables 2 and 3, using its own consecutive numbering. Missing evaluations and figure captions follow the paper; reported detection times are measured mean durations.

GitHub Pages serves the root directory of the `main` branch.
